# Learning OS — Вера

Личный пульт обучения: программа на 16 недель, XP и уровни, ежедневные задания,
карточки для повторения, карта навыков и дневник.

Это не «курс, который надо пройти». Это инструмент, которым ты пользуешься каждый день,
и одновременно твой первый проект, который будет расти вместе с тобой.

---

## Как открыть

Дважды кликни по `index.html` — откроется в браузере. Всё.

Или запусти `открыть.cmd` — то же самое, но одним кликом.

Сервер не нужен, интернет не нужен. Всё работает локально.

---

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | главная страница, каркас интерфейса |
| `styles.css` | внешний вид: цвета, сетки, карточки |
| `data.js` | вся программа: 16 недель, 96 дней, ачивки, карточки |
| `store.js` | прогресс, XP, уровни, streak, повторения |
| `app.js` | логика экранов и действий |
| `materials/week-01.html` | материалы первой недели |
| `materials/week-02.html` | материалы второй недели: HTML, формы, CSS, box model, flexbox |

Порядок загрузки в `index.html` важен: `data.js` → `store.js` → `app.js`.
Каждый следующий файл использует то, что создали предыдущие.

## Где хранится прогресс

В `localStorage` браузера — то есть внутри самого браузера, на этом компьютере.
Никакого сервера и никакой отправки данных.

Это значит:

- если очистить данные браузера — прогресс исчезнет;
- если открыть сайт в другом браузере — там будет пусто;
- **раз в неделю делай экспорт**: шестерёнка → «Экспорт прогресса». Сохрани файл
  в папку проекта или в облако.

Импорт — там же, в настройках.

## Первый запуск

1. Открой `index.html`.
2. Нажми «Материалы дня» — там программа первого дня: три блока теории,
   две лаборатории в терминале и разбор ошибок.
3. Иди по блокам сверху вниз и отмечай задания по мере выполнения.
   День рассчитан на 3–3,5 часа в первую неделю и на 5 часов начиная со второй.
   Темп можно подстроить под себя.
4. В конце дня — дневник и кнопка «Закрыть день».

Если день не задался — кнопка «Закрыть минимальный день». 20 минут, 20 XP, streak жив.
Это не читерство, это часть системы.

---

## Правила игры

- **Никогда не ноль.** Минимальный день — 20 минут.
- **2 заморозки в месяц.** Легальный пропуск без вины.
- **День не закрыт, пока нет записи в дневнике.**
- **Код, который не понимаешь, — не коммитишь.**
- **ИИ предлагает. Ты решаешь.**
